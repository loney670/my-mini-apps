# 🎁 Gift Cases — Telegram бот + Mini App

Бот с мини-приложением: пользователи открывают кейсы (бесплатный раз в 8 часов
и платный за ⭐ Telegram Stars) и получают анимированные подарки. Управлять
может только владелец (ты), остальные — только играют.

## Структура проекта

```
project/
├── bot/
│   └── bot.py            # телеграм-бот (кнопка мини-аппа, оплата Stars, /admin команды)
├── backend/
│   ├── api.py             # FastAPI backend для мини-аппа + отдаёт сам webapp
│   └── database.py        # вся работа с базой данных и логика кейсов
├── webapp/
│   ├── index.html         # мини-апп: заставка, вкладки Главная/Кейсы/Игры/Профиль
│   ├── style.css
│   ├── app.js              # рулетка открытия кейса, оплата, навигация
│   └── assets/gifts/       # видео и превью подарков (Мишка, Подарок, Тортик...)
├── db/
│   └── schema.sql          # схема + стартовые кейсы с процентами выпадения
├── .env.example
├── requirements.txt
└── .gitignore
```

## Кто владелец

В `.env` укажи `OWNER_ID` — твой Telegram ID (узнать у @userinfobot).
Только с этим ID будут работать команды `/admin`, `/give`, `/ban`, `/setweight`.
Все остальные просто пользуются приложением.

## Шансы в кейсах (уже настроено в schema.sql)

- **Бесплатный кейс** (раз в 8 часов): 70% — пусто, 30% — делится поровну между
  всеми 7 подарками (~4.3% каждый).
- **Премиум кейс** (25 ⭐): 50% — Мишка, 50% — делится поровну между остальными
  6 подарками (~8.3% каждый).

Поменять шансы можно командой боту: `/setweight <item_id> <вес>`
(id предметов — в таблице `case_items` в базе).

## Установка и запуск

1. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Скопируй `.env.example` → `.env` и заполни:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `OWNER_ID` — твой Telegram ID
   - `WEBAPP_URL` — адрес, на котором будет открыт мини-апп (см. деплой ниже)

3. Запусти backend (отдаёт мини-апп + API):
   ```bash
   cd backend
   uvicorn api:app --host 0.0.0.0 --port 8000
   ```

4. В отдельном терминале запусти бота:
   ```bash
   python bot/bot.py
   ```

## Деплой (чтобы мини-апп был доступен по https)

Telegram требует, чтобы Mini App был на `https`. Проще всего:
- **Railway.app** или **Render.com** — бесплатный хостинг, задеплой `backend/`
  как Python-сервис (команда запуска: `uvicorn backend.api:app --host 0.0.0.0 --port $PORT`),
  бота — вторым сервисом с командой `python bot/bot.py`.
- Полученный https-адрес backend'а впиши в `.env` как `WEBAPP_URL`.
- В [@BotFather](https://t.me/BotFather) → `/mybots` → твой бот → `Bot Settings` →
  `Menu Button` → укажи тот же URL, чтобы кнопка открытия была и в меню бота.

## Как подключены подарки

Видео подарков лежат в `webapp/assets/gifts/*.mp4`, превью (первый кадр) —
`*.jpg`. Чтобы добавить новый подарок: положи файлы в эту папку и добавь
строку в `case_items` в `db/schema.sql` (или через SQL-клиент в уже созданную
`db/bot.db`).
