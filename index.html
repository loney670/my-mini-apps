Создание публикации

01 / EDIT
Выдели слово или фразу в тексте, нажми «Ссылка на выделенный текст» и введи URL.
При отправке через Bot API публикацию создаёт бот. В канале пост может отображаться от имени канала при соответствующих правах.
Обратный отсчёт будет отображаться прямо в тексте поста. Чтобы обновлять его в опубликованном сообщении и удалить сообщение по окончании времени, нужен постоянно работающий сервер.
Выбери, показывать кнопки в два столбца или каждую на отдельной строке.
0 кнопок
У каждой кнопки есть свой текст и ссылка. Можно добавлять несколько рядов; для Telegram указывается URL, начинающийся с https:// или http://.
Важно: HTML-файл собирает пост и хранит шаблоны в этом браузере. Для реальной отправки в Telegram потребуется бот и серверный обработчик — токен нельзя безопасно хранить в HTML.
